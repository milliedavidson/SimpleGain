**First public release of Simply Gain**, a free gain plugin by Maxximum Displacement.

It's a volume knob for your DAW: -60 to +30 dB, no zipper noise, zero latency. The ring warms from
apricot to amber as you push it hard, and tells you when you're approaching the limit.

### Download

Pick the file for your system under Assets below.

| System                                      | File                                  | Formats                  |
|---------------------------------------------|---------------------------------------|--------------------------|
| macOS 11 or later, Intel and Apple Silicon  | `simply-gain-0.1.0-mac.zip`           | Audio Unit, VST3         |
| Windows 10 or later, 64-bit                 | `simply-gain-0.1.0-windows.zip`       | VST3, standalone app     |
| Linux, 64-bit Intel/AMD                     | `simply-gain-0.1.0-linux.tar.gz`      | VST3, standalone app     |

The Windows and Linux files appear a few minutes after this release is published, once GitHub has
finished building them.

### Install

Each download has a `How to install.txt` with the steps for your system, and they're all in the
[Quick start](https://github.com/milliedavidson/simply-gain#quick-start).

### Good to know

- **Not signed or notarised yet.** On a Mac you need one Terminal command, and Windows shows a
  SmartScreen warning for the standalone app. A signed installer is on the to-do list.
- **Windows and Linux builds are new.** They're built automatically and I develop on a Mac, so
  please tell me if something's off on your machine.
- **Open source.** My code is MIT. JUCE is used under the AGPLv3, so the plugin is distributed under the
  AGPLv3 with the source in this repository. Licences for everything are in the zip's `Licences` folder.
